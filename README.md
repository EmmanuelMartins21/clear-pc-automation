# Clear PC Automation

Uma ferramenta em Python para automatizar a limpeza e otimização do computador.

## Funcionalidades

- Limpeza de arquivos temporários
- Remoção de cache
- Gerenciamento de processos
- Otimização de disco

## Requisitos

- Python 3.8+
- Permissões de administrador

## Instalação

```bash
pip install -r requirements.txt
```

## Uso

```bash
python main.py
```
